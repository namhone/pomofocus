## 🌟 Tính Năng Nổi Bật

- **Stealth Dark Mode & Monochrome UI**: Gam màu Đen - Trắng - Xám hiện đại, loại bỏ ánh sáng xanh chói lọi, tối ưu sự tập trung.
- **Bộ Ba Widget Năng Suất**:
  - **Đồng hồ Pomodoro**: 25/5/15 phút, tự chuyển hiệp, âm báo đa tầng.
  - **Quản lý Nhiệm vụ (Tasks)**: Phân loại theo mức độ ưu tiên P1/P2/P3.
  - **Sổ tay Ghi chú (Notes)**: Markdown tức thì, tự lưu đa thiết bị.
- **Phòng Học Trực Tuyến Live (WebRTC Full-Mesh)**:
  - Video & Voice P2P ổn định, cơ chế ICE Restart tự hồi phục mạng.
  - **Bảng vẽ cộng tác (Whiteboard Pro)**: Chia sẻ ý tưởng, vẽ nét mượt, chèn tài liệu và xuất ảnh.
  - **Cửa sổ âm thanh nổi (Media PiP 16:9)**: Hòa âm thiên nhiên Lo-Fi & đồng bộ YouTube không gián đoạn.
- **Bảo Mật Tiêu Chuẩn Doanh Nghiệp**:
  - Xác thực 2 bước bằng mã thời gian thực (**TOTP / Google Authenticator RFC 6238**).
  - Quản lý phiên, đăng xuất từ xa và xóa tài khoản theo tiêu chuẩn GDPR.
- **Bảng Giá SaaS Freemium Thích Ứng**:

  - Cổng thanh toán chuyển khoản tự động 24/7 qua VietQR Vietcombank (`1066633885` - `HO NGOC BAO NAM`).

## 🚀 Cài Đặt & Phát Triển Cục Bộ

```bash
# Cài đặt thư viện phụ thuộc
npm install

# Khởi chạy môi trường phát triển
npm run dev

# Chạy kiểm thử đơn vị & tích hợp (Vitest)
npm test -- --run

# Đóng gói sản phẩm (Production Build)
npm run build
```
